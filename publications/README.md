# Self-hosted paper PDFs

Drop author-accepted manuscripts here, named after the DBLP key with slashes
replaced by dashes:

    conf/icse/SteinmacherCTG16   ->   conf-icse-SteinmacherCTG16.pdf

`missing_pdfs.md` in the repo root lists every paper that has no open version
yet, with the exact filename to use. A PDF here takes priority over the
open-access link and the arXiv preprint, so it is also how you override a bad
publisher link.

Check the venue's self-archiving policy first — most ACM and IEEE conferences
allow hosting the accepted manuscript.
